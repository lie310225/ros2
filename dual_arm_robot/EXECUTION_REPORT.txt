🤖 机器人规格

底盘:
  尺寸:  0.8m × 0.6m × 0.15m
  重量:  10 kg
  驱动:  差分驱动 (4主动轮 + 2万向轮)

左/右机械臂 (各):
  自由度: 4 DOF + 夹爪
  肩关节:  ±180°
  上臂:    ±90°
  下臂:    ±90°
  夹爪:    可调开合

传感器:
  LiDAR:  360° 扫描, 10m 范围, 10Hz
  相机:   640×480, 深度 0.1-100m, 30FPS

🎯 在目标环境中的使用步骤

步骤 1: 复制项目到 ROS2 工作空间
  
  mkdir -p ~/ros2_ws/src
  cd ~/ros2_ws/src
  cp -r /path/to/dual_arm_robot .

步骤 2: 安装依赖 (需要网络)
  
  cd ~/ros2_ws
  rosdep install --from-paths src --ignore-src -r -y
  
  或手动安装:
  sudo apt install ros-humble-desktop
  sudo apt install gazebo
  sudo apt install ros-humble-gazebo-ros-pkgs

步骤 3: 构建项目
  
  cd ~/ros2_ws
  colcon build
  source install/setup.bash

步骤 4: 启动仿真 (方法任选)

  方法 A - 使用菜单 (推荐):
    python3 ~/ros2_ws/src/dual_arm_robot/launch_menu.py
  
  方法 B - 命令行启动:
    ros2 launch dual_arm_robot robot.launch.py
  
  方法 C - 仅 Gazebo:
    ros2 launch dual_arm_robot robot_gazebo.launch.py
  
  方法 D - 仅 RVIZ:
    ros2 launch dual_arm_robot robot_rviz.launch.py

步骤 5: 控制机器人

  键盘控制底盘:
    ros2 run teleop_twist_keyboard teleop_twist_keyboard
  
  交互式控制器:
    ros2 run dual_arm_robot interactive_controller
